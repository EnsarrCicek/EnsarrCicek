## 🧠 Featured Project

### AI-Powered Call Routing IVR System

An intelligent voice-based call routing system developed for a municipal call center infrastructure.

The system receives caller speech, converts it to text using Speech-to-Text technology, analyzes the caller intent with NLP and FastText-based classification, and routes the caller to the correct internal department through FreePBX/Asterisk.

**Key Technologies:**

- Python
- Asterisk / FreePBX
- AGI scripting
- SIP / IVR
- FastText / NLP
- Whisper Speech-to-Text
- Linux
- Logging and debugging
- Dataset preparation and model testing

**Main Features:**

- Voice-based caller intent detection
- Automatic department routing
- Rule-based and ML-based classification
- Business-hours and after-hours routing logic
- Real-world PBX integration
- Speech-to-text based automation
- Trace logging and debugging support
